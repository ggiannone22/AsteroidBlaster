## Asteroid Blaster


A classic Asteroids-style game built with Python and Pygame.

## Pictures

![alt text](image.png)

## Features

- Player-controlled spaceship
- Rotating and shooting
- Asteroid movement and splitting
- Collision detection
- Score tracking

## Requirements

- Python 3.10+
- uv

## How to play

uv run main.py

## Controls

W / S: Move forward/backward
A / D: Rotate
Space: Shoot
